## 锁定结论速查

| 项 | 结论 |
|----|------|
| 交付物 | 新 H5 FTL（合并），非 SPA、不改打印热敏 |
| 数据 | 两份旧 JSON 拼盘占位，不调接口 |
| 支付 | 只用 `tradeInfo`；无则整块隐藏 |
| 胶囊 | 有桌台只类型；OO 无桌台有码：`类型 / 码` |
| 弹层 | 做；靠 `taxFeeDetailInfo` |
| 砍模块 | Q10=A |
| OKR | KR1/KR2/KR3 材料 + 本对话文件 |
| 工时 | 手写 14h / AI 目标 7h |
| 布局 | `tr/td` |

设计树 frontier 已空。改口径先改 ADR，再改 FTL。
